增加对 DSH v0.1.7 的适配。

## 体验优化

- 支持向前兼容：插件降级后，依然能最大限度的读取高版本的配置。
- 更新了模型缓存。
- 优化了UI文本，现在插件管理页面下能随语言切换标题、描述。（需要 DSH v0.1.7 或以上版本）
- 考虑到模型页面可以设置「上下文窗口」、「输出上限」、「图片模态」，因此【重置模型】改为【重置推理级别】，仅清除推理级别字段，其余字段请自行修改。

## 问题修复

- 现在支持在 DSH v0.1.7 中运行插件。

## 其他变更

### 升级 DSH 到 v0.1.7 时的兼容性问题

> [!TIP]
> 如果要升级 DSH 到 v0.1.7，建议先升级插件，否则将会因兼容性导致 DSH 无法启动。

> [!IMPORTANT]
> 若确实因为先升级插件导致 DSH 无法启动（插件 `<=v0.15.0`且 DSH `>=v0.1.7`），则按以下步骤处理/恢复（以下教程默认已经安装了 DSH v0.1.7 + dsh-model-fix v0.15.0）：

- 停止 DSH
- 卸载插件：
```bash
dsh plugin --profile web remove dsh-model-fix
```
- 如果`~/.dsh/settings.yaml.imported`存在，则改名为`settings.yaml`
- 安装插件：
```bash
dsh plugin --profile web add https://github.com/TikaFlow/dsh-model-fix/releases/latest/download/dsh-model-fix.tgz
```
- 启动 DSH：
```bash
dsh web
```

那么，DSH 将会重新导入配置。
